# sxs-interactive



### Adding new waveforms

_You can find the catalog of waveform simulations [here](https://data.black-holes.org/simulations/index.html)

1. Install marimo
2. Clone the repo
   ```sh
   git clone https://github.com/chengj7/sxs-interactive-plots.git
   ```
3. Navigate to the marimo data files directory
4. Run the script premarimo_load.py to generate a new data file
5. Run SXSInteractivePlots.py in .../sxs-interactive-plots/plots directory with marimo on your local machine
   ```sh
   marimo run SXSInteractivePlots.py
   ```
7. New waveforms should appear under 'Custom' tab
